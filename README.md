# Hospital-Operations-Patient-Analytics

 Project Overview
 
The Hospital Operations & Patient Analytics Dashboard is an end-to-end data analytics project designed to analyze hospital operations and transform raw healthcare data into actionable business insights. The project focuses on evaluating patient flow, department performance, hospital revenue, treatment costs, waiting times, payment methods, and patient satisfaction using industry-standard analytics tools.

The project follows the complete data analytics lifecycle, beginning with data preparation in Excel, followed by SQL-based data analysis, exploratory data analysis (EDA) using Python, and the development of interactive dashboards in Power BI and Tableau. The final outcome provides meaningful insights that can support operational decision-making and improve hospital performance.

Project Objectives
Analyze patient demographics and hospital visit patterns.
Evaluate department-wise patient volume and operational performance.
Measure hospital revenue and treatment cost trends.
Monitor patient waiting times across departments.
Analyze payment mode preferences.
Evaluate patient satisfaction levels.
Develop interactive dashboards for business reporting and decision-making.
